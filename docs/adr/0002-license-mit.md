# ADR 0002: MIT license

- **Status:** Accepted
- **Date:** 2026-11-06

## Context

The repository is intended as a public showcase. The vision left MIT vs
Apache-2.0 open. Both are permissive and common for systems code.

## Decision

Release under the **MIT** license (`LICENSE` at the repository root).

## Consequences

- Simple terms for readers who copy snippets or methodology.
- No explicit patent grant (unlike Apache-2.0); acceptable for this personal
  learning/showcase scope. Revisit only if contributors or corporate use require it.
